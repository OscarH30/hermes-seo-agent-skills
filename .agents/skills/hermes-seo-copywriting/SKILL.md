# Hermes SEO Copywriting

Write a review-ready draft from a selected content brief and approved evidence. The page must serve the reader’s intent before it serves a keyword.

## Boundary

- Require a defined audience, page job, primary intent/theme, conversion action, approved voice, and claims/source plan. If absent, return a short GAP list or use `hermes-seo-strategy` first.
- Label supplied facts as OBSERVED and any proposed interpretation as INFERRED; keep missing proof as GAP.
- Never invent outcomes, testimonials, reviews, citations, pricing, locations, certifications, product features, legal claims, or metrics.
- Do not copy competitors. Do not keyword stuff.
- Drafting is not publishing. CMS changes, external links, schema implementation, and publication require explicit human approval.

## Writing method

1. Lead with the reader problem and a direct, evidence-supported answer or value proposition.
2. Use customer language only when sourced. Prefer specific, attributable outcomes over jargon.
3. Build one argument per section. Use descriptive headings, short paragraphs, lists only when useful, and tables only when they clarify a real comparison.
4. Establish demonstrated experience and accountable expertise. When the owner, founder, or relevant subject-matter expert has an accurate team, author, or bio page on the site, use an attributable quote only if it is supplied or approved, identify that person truthfully, and suggest one contextual internal link to their page. Never invent, paraphrase as a quotation, or imply endorsement by an owner or expert.
5. Make factual statements proportional to evidence. Use Firecrawl MCP or Perplexity MCP for source discovery when available, then open and verify the primary or official source before citing it. Cite real, directly relevant sources close to the claim; flag claims that still need subject-matter, legal, brand, or owner review.
6. Run a human-author pass before delivery: replace generic transitions, repeated sentence shapes, empty superlatives, keyword repetition, canned conclusions, and unearned certainty with concrete language, natural variation, useful judgment, and clear attribution. Do not imitate a named writer or claim that text will evade AI detectors; the objective is credible, original writing for a human reader.
7. Suggest meaningful internal links, including the verified expert link where appropriate, and eligible schema as implementation notes only.
8. Supply title-tag and meta-description candidates as drafts, not promises of SERP display.
9. Use one clear primary conversion action aligned to intent.

## Deliverable

Start with the audience, page job, evidence limits, source plan, expert/owner attribution status, and claims requiring approval. Then provide three headline options with one-line rationale, a recommended subheadline and CTA, the full sectioned draft, metadata candidates, internal-link/schema implementation notes, and a review checklist. The checklist must confirm source verification, quote approval, expert-link accuracy, authority, usefulness, and human-author quality.

Hand a draft needing refinement to `hermes-seo-editing`. End with the exact approvals needed before publication.
