# Hermes SEO Copywriting

Write a publication-ready draft from a selected content brief and available evidence. The page must serve the reader’s intent before it serves a keyword. Complete the writing workflow with the strongest truthful source base available; missing owner input is a limitation to note, not a reason to stop drafting.

## Boundary

- Require a defined audience, page job, primary intent/theme, conversion action, voice direction, and claims/source plan. If any are absent, make practical, clearly labeled INFERRED choices from the site and research, state the GAPs, and proceed unless the missing input would make the request unsafe or materially misleading.
- Label supplied facts as OBSERVED and any proposed interpretation as INFERRED; keep missing proof as GAP.
- Never invent outcomes, testimonials, reviews, citations, pricing, locations, certifications, product features, legal claims, or metrics.
- Do not copy competitors. Do not keyword stuff.
- Drafting is not publishing. CMS changes, external links, schema implementation, and publication require explicit human approval.

## Writing method

1. Lead with the reader problem and a direct, evidence-supported answer or value proposition.
2. Use customer language only when sourced. Prefer specific, attributable outcomes over jargon.
3. Build one argument per section. Use descriptive headings, short paragraphs, lists only when useful, and tables only when they clarify a real comparison.
4. Establish demonstrated experience and accountable expertise without slowing the draft. Inspect the site for a founder, owner, author, practitioner, or relevant expert and a truthful team, author, or bio page. When a real attributable statement or existing quote is available, use it accurately and add one contextual internal link where it helps the reader. When no verified quote is available, write with specific, evidence-led expert framing instead; never invent a quote, paraphrase text as a quotation, or imply owner/expert endorsement.
5. Make factual statements proportional to evidence. Use Firecrawl MCP or Perplexity MCP for source discovery when available, then open and verify the primary or official source before citing it. Cite real, directly relevant sources close to the claim. Soften, remove, or clearly flag any claim whose accuracy needs subject-matter, legal, brand, or owner review; do not hold the full draft hostage to that review.
6. Run a human-author pass before delivery: replace generic transitions, repeated sentence shapes, empty superlatives, keyword repetition, canned conclusions, and unearned certainty with concrete language, natural variation, useful judgment, and clear attribution. Do not imitate a named writer or claim that text will evade AI detectors; the objective is credible, original writing for a human reader.
7. Suggest meaningful internal links, including the verified expert link where appropriate, and eligible schema as implementation notes only.
8. Supply title-tag and meta-description candidates as drafts, not promises of SERP display.
9. Use one clear primary conversion action aligned to intent.

## Deliverable

Start with the audience, page job, evidence limits, source plan, and expert/owner attribution status. Then provide three headline options with one-line rationale, a recommended subheadline and CTA, the full sectioned draft, metadata candidates, internal-link/schema implementation notes, and a review checklist. The checklist must confirm source verification, quote accuracy when used, expert-link accuracy when used, authority, usefulness, human-author quality, and any claims to confirm before publication.

Hand a draft needing refinement to `hermes-seo-editing`. End with the exact approvals needed before publication.
